## 变更内容

### 新增

- `/models` 接口支持 `page` 与 `limit` 分页参数。
- 对话补全响应新增 `prompt_cache_hit_tokens` 与 `prompt_cache_miss_tokens` 字段。

### 修复

- 修复流式响应在长文本场景下偶发的分片顺序错乱问题。
- 修复 `tools` 参数中函数描述含特殊字符时的解析异常。

### 废弃

- 废弃模型名 `deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp`，请改用 `deepseek-flash`。

## 影响范围

本次更新对现有 OpenAI / Anthropic SDK 调用方式完全兼容，无需修改代码。
